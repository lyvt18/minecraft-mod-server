# Minecraft模組伺服器：記憶體、單核與計費怎麼算，開 Forge／Fabric 整合包不卡頓的選購與開服流程

原版伺服器很好養。一台 2 核 4G 的小主機，五六個朋友玩生存，大概都不會出事。真正把人勸退的是模組服：整合包一載入要等十分鐘，玩家一進世界就開始掉 TPS，方塊挖了不掉、怪物原地漂移。於是你開始查資料，發現有人說要加記憶體、有人說要換高主頻 CPU、有人說乾脆別自己開——三種答案都對，但都不是針對你的情況。

這篇要處理的就是這件事：模組伺服器到底在吃什麼資源、要怎麼把需求換算成配置、以及像雨雲遊戲雲這類租用方案該怎麼挑計費方式才不會多付錢。

## 模組伺服器跟原版差在哪裡

先講三個真正影響體驗的地方，其餘都是細節。

**單核性能決定 TPS 上限。** Java 版服務端的主邏輯跑在單一執行緒上，mod 越多，每個 tick 要處理的東西越多，這條主執行緒就越容易跑不完。結果就是 TPS 掉到 20 以下，玩家端先感覺到的是操作延遲，不是畫面卡。多核心有幫助，但幫不到主執行緒。

**記憶體要留餘量，但它救不了單核。** mod 數量、世界結構生成、玩家分散在不同區域載入區塊，都會推高堆記憶體需求。記憶體不足會直接崩服，所以它是門檻；但記憶體給到 32G 而 CPU 是低主頻老型號，該卡的還是卡。

**版本與視距是最容易被忽略的變數。** 雨雲官方在遊戲雲頁面上講得很直接：1.18+ 的資源消耗大約是 1.16+ 的兩倍、1.12.2 的三倍，原因是世界高度加倍，區塊生成與載入成本跟著上去。官方標示的承載能力，基準是「模組數 50、視距 5」，Fabric 服則是「15 個 mod、視距 5」。也就是說，視距與模擬距離是你手上最便宜的降載工具，比升級方案有效得多。

## 自己開、用家用主機開，還是租？

三條路各有實際成本。

自己在家用電腦開服，最大的問題通常不是 CPU，是上傳頻寬。家用網路的上行多半不對稱，四五個人連進來就開始爆延遲；其次是公網 IP 與 NAT 穿透、機器得 24 小時開著、停電就全村斷線。內網穿透是常見的替代做法，成本最低，但延遲與穩定性取決於穿透服務本身，人數一多就現形。

租用的價值不在於性能數字，而在於固定上行頻寬、機房不斷電、以及被攻擊時有人幫你扛。雨雲這類廠商還額外賣了兩樣東西給遊戲服：一是部分機房自帶 100～200G 高防，二是面板層的一鍵開服與備份。

## 固定計費還是動態計費？先搞懂「CPU 電量」

這是雨雲遊戲雲最值得花五分鐘研究的地方，選錯一年下來差的不只是幾十塊。

固定計費就是傳統的固定租金，價格鎖死。動態計費則是把租金壓低，改成對超過基準的 CPU 使用率按日結算，也就是俗稱的 CPU 電費。官方規則寫得很明確：CPU 使用率基準值 20%，低於 20% 不耗電，高於的部分才算；記憶體等其他資源不產生電費；每日會依產品核心數贈送免費電量，而且可以跨日累積。面板服另外支援按日計費，用餘額結算下一天的日租。

判斷邏輯因此很簡單：模組服的 CPU 佔用幾乎不可能長期壓在 20% 以下，只要你是「每天晚上固定開、有人掛機、玩家會跑圖」的長期服，直接選固定計費。反過來，週末才約開兩小時、或只是拿來測試整合包相容性，動態計費才是真的省。官方論壇上也有人用中等負載的生存服做過對比，結論一致——低負載才省，重負載選固定。

## 從下單到整合包上線

雨雲的購買流程是「選產品類型→機型→機房→計費模式→配置→公網 IP→系統與軟體安裝」，支援 Linux 與 Windows，也可以預裝面板環境。實際開一個模組服的順序大致是：

1. 下單並選擇預裝面板（雨雲自家面板或 MCSM 面板），面板支援 Forge／Fabric 等多個版本，也有可視化管理介面。
2. 進面板後選服務端類型與版本，建立實例；大型整合包建議直接上傳整合包或使用面板的整合包安裝功能，比自己逐個丟 mod 穩定。
3. 分配 JVM 記憶體時留餘量，不要把 8G 主機的堆記憶體開到 7.5G，系統本身與備份也要吃。
4. 調低視距與模擬距離。這一項對 TPS 的改善通常比升級一級方案還明顯。
5. 處理連線：NAT 機型在控制台設定連接埠映射（預設可開 15 條），有獨立 IP 的機型直接用 IP 加連接埠。
6. 開服前先確認客戶端與伺服端 mod 對齊——只裝在客戶端的 mod（介面、效能類）不要丟到伺服器，反之亦然，這是最常見的崩服原因。
7. 設定管理員帳號，然後開啟面板備份。存檔是模組服最貴的東西，機器可以重開，世界沒了就沒了。

如果只是想先確認延遲體感，1 元試用一天是最省事的做法，比任何評測數字都準。雨雲另外提供 7 天無理由退款，每個帳號限 3 次。

## 幾個買之前該問自己的問題

- **你的機房在哪，玩家在哪？** 遊戲雲機房都在中國大陸，台灣或海外玩家連線會走國際線路，延遲體感差異不小。要給非大陸玩家玩，先在試用機上實測 ping，或改看雨雲的雲伺服器——那邊有香港、洛杉磯、東京等機房，價格帶也不同，但那是通用雲主機，不像遊戲雲有現成的開服面板。
- **10M 上行夠不夠？** 模組服的上行主要花在區塊同步與玩家進出，人數不多的情況下 10M 通常夠，但如果你的玩法是大量實體、多人跑圖，把頻寬算進去比較保險。
- **30+20G 硬碟夠不夠？** 200+ mod 的整合包本身就吃掉不少空間，加上世界存檔會持續長大，長期服建議一開始就把擴容成本算進月費。
- **續費貴不貴？** 首月 5 折和年付 7 折都是真的，但優惠不等於長期定價。打算開一年以上，直接按年付或積分續期的實際單價去比較。

## 常見問題

**2 核 4G 能開模組服嗎？** 能，但官方標示的承載是模組服 6 人、200+ mod 整合包 1 人。當練手或小圈子玩可以，不要預期它能撐一個社群。

**一定要買獨立 IP 嗎？** 朋友私服不用，NAT 機型有 15 條連接埠映射可分配。要固定 IP、要多開多個服務、或不想跟別人共用 IP，再加購。

**動態計費的電量會超出預算嗎？** 官方有每日依據核心數贈送的免費電量，且可累積，輕負載幾乎不花錢；但重負載的模組服容易把省下的租金補回去。這也是為什麼先試一天、看一下實際 CPU 曲線再決定計費模式，比看任何攻略都可靠。

**跟自助開服相比值得嗎？** 如果你只是偶爾跟兩三個朋友玩原版，家用主機加穿透是最省的，不用多想。如果你要的是「開著就有人能連、爆掉能重啟、世界有備份」，那租金買的就是這三件事。

整體判斷：這個方案最適合的是**小型到中型模組服**——四到十幾個玩家、跑 50 到 200 個 mod、需要面板一鍵開服與備份、預算抓在每月一到兩百人民幣這個區間。最不適合的是國際玩家為主的伺服器，以及想用最低預算硬跑超大型整合包的場合；前者該換機房，後者該換檔位，兩件事都不是靠調視距能解決的。
